# 路线图 — PITBOARD 周刊

商业模式：年订（¥199/年，单 SKU）→ Pancake 收款 → 邮箱 double opt-in →
每周六 08:00 出刊通知直达 → 网页全文与归档 → 到期提醒 → 续订顺延。
独立开发者的闭环关键：单期 LLM 成本几元，一个年订户覆盖全年成本；公开面
只有卷首 + 头条 + 目录（获客），付费正文只进订阅者邮箱与网页。

pitboard🔗ℹ

turinglambdaai

 (require pitboard) package: pitboard

汽车行业每日热点日报引擎：抓取 RSS 媒体源、GitHub 汽车话题仓库与 arXiv 论文，聚簇去重，按独立来源数与时间衰减计算热度，输出站点、RSS、JSON API、Markdown 日报与 llms.txt。

1 命令行🔗ℹ

raco pitboard fetch  [--date YYYY-MM-DD] [--data DIR] [--config FILE] [--no-llm]

raco pitboard serve  [--port N] [--data DIR] [--assets DIR]

raco pitboard export [--out DIR] [--data DIR] [--domain D] [--base-url U]

2 LLM 增强（可选）🔗ℹ

设置 PITBOARD_LLM_API_KEY（必填）、PITBOARD_LLM_BASE_URL （默认 https://api.deepseek.com）、PITBOARD_LLM_MODEL （默认 deepseek-chat），任何 OpenAI 兼容接口均可。未配置时引擎以 纯排序模式运行，站点功能不受影响。

3 Agent 出口🔗ℹ

  • /rss.xml — RSS 2.0

  • /api/v1/latest.json 与 /api/v1/digest/<date>.json

  • /daily/<date>.md — Markdown 日报

  • /llms.txt — 站点索引

  • /api/events — SSE 出刊推送

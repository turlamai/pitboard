# PITBOARD 周刊 — 设计契约

修订：2026-11-22-journal-v1 · 起始 SHA：pitboard main `e322e77`（改造前免费日报站）

## Brief

pitboard 从免费汽车日报站改造为**付费汽车行业期刊订阅站**（周刊）。

- **商业模式**：单 SKU 年订（原型示例 ¥199/年）；付费墙只展示一部分——当期网页版可见「卷首按语 + 本周头条全文 + 本期目录」，其余条线、数据版、大事记订阅可见；付费价值 = 每周出刊通知直达 + 网页全文与完整往期归档 + 装帧体验。
- **交付形态（2026-11-22 拍板）**：交付主体是**网页全文**（订阅状态解锁，magic link 无密码登录、邮箱即身份）；邮件只做**出刊通知**（报头 + 卷首一句 + 头条标题 + 免登录直达链接，每周六 08:00）；全文不进邮件；PDF 不做，「装订感」若未来有需求走 print CSS 年度合订本（可选，不进常规管线）。
- **主任务**：① 读者：舒服地读完一期高质量行业期刊，续订意愿成立；② 潜在读者：一眼看懂价值，完成订阅决策。
- **技术线**：Web（policy 路由），Racket 全栈延续，pitboard 仓内升级，不新开仓。
- **节奏**：周刊，每周六 08:00 出刊（原型示例值，可改）。
- **内容结构**：不沿用老报纸版面骨架，按汽车行业信息消费习惯组织——卷首按语 → 本周头条（深度综述）→ 固定条线（政策与法规 / 智能化 / 三电与供应链 / 整车与市场）→ 数据版 → 大事记 → 主编按语收尾由卷首承担。条线划分在打磨期可调，结构不变式是「条线制」而非具体条线集合。
- **运营形态**：AI 流水线（信源→聚簇→精选→汇编，LLM 仅周度介入）+ 主编把关；原型中的条目文案均为示例数据。

## 设计原则

**王垠排版内核 × 家族 HIG 约束**（用户指定设计品味参照）：

- 内容至上、零装饰：无渐变、无玻璃、无花哨动效、无装饰图；层级只由字号、字重、留白与细分隔线承担。
- 排版即设计：阅读正文一律衬线栈、行高 1.85、版心约 46–50 个中文字符宽；标题衬线 500–600 字重，不靠加粗堆层级。
- 纸感中性：暖纸底 + 墨色正文（家族 site-kit 调色，沿 yinwang-archive 实物提取），赤陶强调色只用于链接与主动作，永不大面积使用。
- 期刊装帧语义是唯一允许的例外：报头上下双线（上 2px 下 1px）作为「报头」设备、期号行的花线，属于内容装帧而非 UI 装饰。
- 付费锁定用**清晰声明**（目录 + 条数），不用模糊、遮罩、渐隐把戏。
- 家族基线其余项（可访问性对比度、键盘、状态完整性）全量适用，不因「报刊风」豁免。

## Tokens

语义角色唯一值表真源：`prototype/shared.css`（亮暗成对，逐值沿 yinwang-archive 提取的家族 site-kit palette；偏离 site-kit 的两项是 `--text-3` 与强调色，各见下）。要点：

- 画布 `--bg` 暖纸 / 深墨两档；正文 `--text`、辅助 `--text-2/3`、边界 `--border`、强调 `--accent`（赤陶，暗色提亮档）、强调之上的文字 `--on-accent`、选区 `--selection`。
- `--text-3` 不取 site-kit 值：`#A8A29E` / `#78716C` 在画布与表面上只有 2.36–2.52:1 / 3.41–3.82:1，校正为 `#776F6A` / `#8D8782`（4.60–4.92:1 / 4.61–5.17:1），三级文字层级不变。
- 强调色不取 site-kit 值（浅色）：site-kit 赤陶 `#D97757` 上压白字只有 3.12:1，作链接对纸底 2.92:1；浅色校正为 `#B34B29`（同一色相加深），暗色保留 site-kit 档 `#D4915C`。见「对比度落地」。
- 字体角色：UI = 系统 sans 家族默认栈；**阅读正文与标题 = 衬线栈** `Songti SC / Noto Serif SC / SimSun / Georgia`（原型零外部依赖不嵌字体；实物若系统栈跨端观感不足，评估自托管 Noto Serif SC 子集——policy 禁远程字体）。数据用 tabular-nums；邮箱地址、日期戳可用等宽角色。
- 尺度：辅助 12 / 条线节标 13 / 条目摘要 15 / 阅读正文 17 / 条目标题 20 / 头条 26 / 报头 34；行高：正文 1.85、UI 1.5。
- 密度预设：阅读（内容留白 24–32，分组间距 32–48——期刊节间距取上限值，装帧语义已记入例外）。
- 版心：`clamp(720px, 14vw + 560px, 820px)`（约 46 字/行）。

## 组件词汇

报头 masthead（刊名 serif + 双线 + 期号行）· 卷首按语 · 头条块（标题/元信息/综述/为什么重要/原文链接）· 条线节（节标 + 花线 + 条目列）· 条目（标题 + 答案先行摘要 + 入选理由 + 原文链接）· 数据表（hairline 表，tabular 数字）· 大事记（日期戳 + 一行事实）· 订阅卡（价格 + 支付方式 + 流程）· 目录清单（锁定态展示形态）· 往期归档列表（年份分组 + 期号/头条标题/条数/可见性，锁定期标题仍可读——标题是获客面）· 期际导航（上一期/下一期，最新一期以 muted 文本标注）· 确认订阅邮件（double opt-in：支付 ≠ 生效，magic link 72h 有效）· FAQ · 页脚（版权/退订/更正声明）· 评审工具条（非产品 UI，验收后移除）。

## 不变式

1. 正文永远衬线阅读预设；UI 元素（按钮、节标、元信息）永远 sans——两套角色不混。
2. 每个条目必有原文链接；入选理由一句话必须有（这是付费筛选价值的可见化）。
3. 锁定态 = 卷首 + 头条全文 + 目录可见，其余以清晰声明隐藏——任何屏不许出现「看似有内容实际读不了」的模糊把戏。
4. 亮暗双主题成对；暗色为深墨纸感（非纯黑）。
5. 邮件只做**出刊通知**（内联样式窄列：报头 + 卷首一句 + 头条标题 + 直达链接），**全文永远在网页**——不建全文邮件渲染管线；PDF 不做。
6. 零外部依赖（原型）；强调色不出现在大面积区域；一屏最多一个高强调主动作（订阅卡 CTA）。

## Exit 条件

- **关键屏**：期刊页·锁定态（访客视角）／期刊页·解锁态（订阅者视角）／订阅落地页／出刊通知邮件预览／往期归档／订阅确认邮件预览。
- **交互逻辑**：亮暗主题切换；样刊预览 → 落地页 → 订阅流程（支付方式 → 邮箱 → 确认邮件）；锁定态与解锁态的信息边界一致且可解释。
- **验收**：家族 UI 验收清单（原型阶段适用项）+ HIG + 用户满意。样刊内容为示例数据，不构成对真实事件的陈述。

## 气质档位声明与对齐 — 2026-11-26（家族规范 `2026-11-26-temperament-profiles`）

本轮按 owner 指令对全部产品原型过一遍新规范。做法是「声明档位 + 对齐受影响的差量 + 记录遗留」：没有重绘任何屏幕，没有改动信息架构，也没有新增 token 值表。**档位由 agent 代为判定，待 owner 确认或更正。**

### 档位

- **主档位**：静读。付费汽车行业期刊，主体是每周一期的人工阅读。
- **主任务**：沿用上文 Brief，本节不复述。
- **与静读默认的差量**：正文用衬线，版心 38 个汉字（17px）；营销首页与期刊共用同一容器宽度。
- **借用档位**：数据版与大事记借监控档的数字排版（等宽数字）。
- **工作台结构**（§9）：沿用现有布局，本轮未调整面板；「同一时间最多一个从属面板」留到核心屏打磨轮核对。

### 本轮改动

- 字体栈：UI 栈与等宽栈在通用回退前补 CJK 回退（§9「等宽与中文」）；值仍只维护在 `shared.css`。
- 排版基线块：`body { text-autospace: normal; line-break: strict }`、中性 `scrollbar-color`（§10）。本仓已有的 `::selection` 保留。
- `--max-w` 由 `clamp(720px, 14vw + 560px, 820px)` 收到 `clamp(680px, 14vw + 520px, 699px)`：期刊正文原约 40 个汉字一行，现 38 个（内容 651px）。

### 测量

无头 Edge 1280×800（移动页 390×844），亮暗各渲染一次，逐页统计；对比度为脚本近似计算（半透明高亮底、彩色 emoji、content 里的符号会被误计）。

正文超版心 64→44：剩余是 `journal-full.html` 与 `landing.html` 的 651px 段落，即 17px 下的 38 个汉字，正好在上限；低对比文字 0→0。
